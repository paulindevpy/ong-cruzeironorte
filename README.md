# ONG CruzeiroNorte - SPA (TRABALHO FACULDADE)

Projeto desenvolvido para avaliação acadêmica.

## Tecnologias
- HTML5 Semântico
- CSS3
- JavaScript Vanilla (ES6 Modules)
- Chart.js via CDN
- LocalStorage

## Instalação e Execução
1. Clone o repositório: `git clone <URL_DO_REPOSITORIO>`
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` através de um servidor local (ex: Live Server).

## Versionamento
Este projeto utiliza GitFlow e diretrizes do Conventional Commits.
